# [기획] 게시물 → 프로젝트 쇼케이스 (영상 · 발표자료 · 사용자 가이드)

- 관련: [`2026-11-06-pivot-summary.md`](2026-11-06-pivot-summary.md) 11장 7번 "공개 포트폴리오 링크 다듬기" — 3 · 4단계는 이 작업에 묶는다

---

## 1. 목표

게시물을 "글"이 아니라 **내가 배포했거나 만들었던 프로젝트를 모아 보여주는 카드**로 바꾼다.
한 프로젝트에서 배포 링크 · 데모 영상 · 발표자료 PDF를 한 화면에서 볼 수 있어야 한다.

**원칙:** 영상과 PDF는 **링크 임베드가 기본**이고, 직접 업로드는 보조로 둔다. 저장공간과 전송량 부담을 우리 쪽에 쌓지 않는다.

## 2. 이미 있는 것

| 기능 | 위치 | 비고 |
| --- | --- | --- |
| 배포 링크 | `LinkType.DEPLOY`, `PostHero` 버튼 | GitHub homepage에서 자동으로 채움 |

| 프로젝트 ↔ 게시물 | `Project.post_id` | 프로필 `ProjectsTab` |

## 3. 단계별 작업

| 단계 | 작업 | 크기 |
| --- | --- | --- |
| 1 | 영상 링크 (`LinkType.VIDEO`) + 유튜브 가이드 | 작음 |
| 2 | PDF: 구글 드라이브 링크 옵션 + 업로드 한도 축소 + 고아 Blob 정리 + PDF 가이드 | 작음 |
| 3 | 상세 페이지를 쇼케이스 순서로 재배치 | 중간 |
| 4 | 프로필 · 공개 포트폴리오 링크에 프로젝트 카드 그리드 | 중간 |

### 3.1 단계 1 — 영상 링크

- 발표자료(document)는 게시물당 1건(`post_documents.post_id unique`)이라 영상을 거기에 넣으면 PDF와 같이 못 쓴다. → **`LinkType.VIDEO`로 추가**한다. links는 여러 개를 받으므로 스키마 변경이 필요 없다.
- **직접 업로드는 하지 않는다.** 유튜브(일부 공개) · 구글 드라이브 링크만 받는다.
- 입력은 사용자가 붙여넣은 아무 형식이나 받고, 프론트에서 embed URL로 바꿔 저장한다 (`lib/slides.ts`와 같은 방식, `lib/video.ts` 새로 만들기).
  - `youtube.com/watch?v={id}`, `youtu.be/{id}`, `youtube.com/shorts/{id}` → `https://www.youtube-nocookie.com/embed/{id}`
  - `drive.google.com/file/d/{id}/view...` → `https://drive.google.com/file/d/{id}/preview`
- 백엔드는 이 두 embed 형식만 정규식으로 허용한다. 임의 URL이 iframe에 들어가면 안 된다.
- 상세 페이지: VIDEO 링크가 있으면 16:9 iframe으로 임베드한다.

**백엔드 변경**
- `LinkType` enum에 `VIDEO` 추가
- `PostLink` 저장 시 VIDEO는 embed 형식 검증 (validator 하나)
- ⚠️ **DB CHECK 제약 확인 필요.** `ddl-auto=update` + PostgreSQL이라 Hibernate 6이 테이블을 만들 때 `post_links_type_check` 같은 enum CHECK 제약을 만들었을 수 있다. `update`는 이 제약을 고치지 않으므로 새 값이 저장 단계에서 거부된다. 배포 전에 아래로 확인하고, 있으면 제약을 지우거나 다시 만든다. (단계 2의 `post_documents`도 같다.)
  ```sql
  SELECT conname, pg_get_constraintdef(oid) FROM pg_constraint
  WHERE conrelid IN ('post_links'::regclass, 'post_documents'::regclass) AND contype = 'c';
  ```
- `docs/db_document.md`의 `post_links.type` 설명 갱신

### 3.2 단계 2 — PDF 용량 대응

| 대응 | 내용 |
| --- | --- |
| 드라이브 링크 기본 | `DocumentType.GOOGLE_DRIVE` 추가, `drive.google.com/file/d/{id}/preview`만 허용. 우리 저장공간 · 전송량 0 |
| 업로드 한도 축소 | 30MB → 10MB (`lib/uploadLimits.ts`, 백엔드 `MAX_PDF_BYTES` 같이). 비싼 건 저장공간보다 **전송량** — 내장 뷰어는 상세 페이지를 열 때마다 파일 전체를 받는다 |
| 고아 Blob 정리 | 현재 게시물 삭제 · PDF 교체 시 Blob을 지우는 코드가 프론트 · 백엔드 어디에도 없다. 지운 PDF가 계속 쌓인다. 교체 · 삭제 시 이전 URL을 `@vercel/blob`의 `del()`로 지운다 |
| 서버 압축 | **하지 않음.** 함수 실행 시간 · 비용 대비 효과가 작다. 대신 가이드에서 압축 도구를 안내한다 |

`DocumentSection`의 탭: **구글 드라이브(기본) / 구글 슬라이드 / 파일 업로드** 순서로 바꾼다.

### 3.3 단계 3 — 상세 페이지 쇼케이스 배치

```
썸네일 + 제목 + [배포 사이트] [GitHub] 버튼
→ 데모 영상
→ 한 줄 소개 · 내 역할 · 기술 (정리 카드에서 가져옴)
→ 발표자료
→ 기타 링크 (Figma · ERD 등)
```

- 모집 관련 섹션(지원 · 포지션)은 숨긴다 (전환 계획 11장 1번과 같이).
- 배포가 끝난 프로젝트는 배포 링크가 없으므로, 그 자리를 데모 영상이 대신한다.

### 3.4 단계 4 — 프로젝트 모아보기

- 프로필 · 공개 포트폴리오 링크(`/profile/[id]`)에 프로젝트 카드 그리드를 둔다. 카드에는 썸네일 · 한 줄 소개 · 기술 · 배지(🌐 배포 · ▶ 영상 · 📄 발표자료)를 보여준다.
- 새 페이지를 만들지 않고 기존 `ProjectsTab`을 다듬는다.

## 4. 사용자 가이드 (입력칸 옆에 접이식으로 노출)

입력칸 옆에 `?` 또는 "어떻게 올리나요?"를 두고, 누르면 아래 내용이 펼쳐진다. 문구는 `messages/*.json`(next-intl)에 넣는다.

### 4.1 유튜브로 데모 영상 연결하기

1. 유튜브 스튜디오에서 **만들기 → 동영상 업로드**를 누른다.
2. 공개 범위를 **일부 공개**로 고른다. 링크를 아는 사람만 볼 수 있고 검색에는 안 나온다. ⚠️ **비공개**로 두면 임베드가 재생되지 않는다.
3. 영상 아래 **공유 → 링크 복사**를 누른다.
4. 복사한 링크를 Pofol의 "데모 영상" 칸에 붙여넣는다. `youtu.be/...`, `youtube.com/watch?v=...` 둘 다 된다.

> 팁: 1~3분짜리 핵심 기능 시연이 가장 좋다. 채용 담당자는 처음 30초 안에 판단한다.

### 4.2 구글 드라이브로 발표자료 PDF 연결하기 (용량 제한 없음, 추천)

1. 구글 드라이브에 PDF를 올린다.
2. 파일을 우클릭하고 **공유 → 공유**를 누른다.
3. "일반 액세스"를 **링크가 있는 모든 사용자 · 뷰어**로 바꾼다. ⚠️ "제한됨"이면 다른 사람에게 보이지 않는다.
4. **링크 복사**를 누르고 Pofol "발표자료 → 구글 드라이브" 칸에 붙여넣는다.

> 구글 슬라이드로 만든 발표라면 PDF로 바꾸지 말고 "구글 슬라이드" 탭에 링크를 그대로 넣는다.

### 4.3 PDF를 직접 올릴 때 (10MB 이하)

- 10MB가 넘으면 압축하거나 위의 드라이브 방식을 쓴다.
- 압축: PowerPoint · Keynote에서 내보낼 때 **"최소 크기" / "인터넷 게시용"**을 고르면 보통 크게 줄어든다.

### 4.4 오류 문구 (가이드로 연결)

| 상황 | 문구 |
| --- | --- |
| 유튜브 · 드라이브가 아닌 링크 | "유튜브나 구글 드라이브 링크만 넣을 수 있어요. [올리는 방법 보기]" |
| PDF 10MB 초과 | "10MB 이하만 올릴 수 있어요. 구글 드라이브 링크로 연결하면 용량 제한이 없어요. [방법 보기]" |

> 링크의 공개 범위(비공개 · 제한됨)는 서버에서 확인할 수 없다. 그래서 저장 후 **미리보기**를 보여주고 "미리보기가 안 보이면 공개 범위를 확인하세요"라고 안내한다.
