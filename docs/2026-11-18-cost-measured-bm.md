## 2. AI 비용 실측

**측정 방법:** `completeJson`이 OpenAI 응답의 `usage`를 기능별로 Redis `ai:tokens:{feature}:{yyyyMM}`에 누적한다. 2026년 11월 로컬 Redis에 쌓인 **21회 호출** 값이다.

**단가:** gpt-4o-mini 입력 $0.15 · 출력 $0.60 / 100만 토큰, 1달러 = 1,400원.

| 기능 | 호출 수 | 1회 입력 토큰 | 1회 출력 토큰 | **1회 비용** | 월 한도 | 한도를 다 쓰면 |
|---|---|---|---|---|---|---|
| 정리 카드 | 8 | 12,632 | 932 | **3.44원** | 10 | 34.4원 |
| 면접 질문 | 6 | 12,288 | 1,449 | **3.80원** | 3 | 11.4원 |
| 구현 설명 | 3 | 8,534 | 521 | 2.23원 | 5 | 11.2원 |
| 프로필 README | 1 | 7,747 | 304 | 1.88원 | 5 | 9.4원 |
| 방향성 분석 | 1 | 7,618 | 258 | 1.82원 | 5 | 9.1원 |
| AI 이력서 | 1 | 8,010 | 372 | 1.99원 | 3 | 6.0원 |
| README 요약 | 1 | 154 | 86 | 0.10원 | 20 | 2.1원 |
| **합계** | **21** | 223,923 (총) | 18,740 (총) | 62.8원 (총) | | **83.5원 / 인 · 월** |

**보통 사용자** (방향성 1 · README 1 · 정리 카드 2 · 구현 설명 1 · 면접 1 · 요약 2): **약 17원 / 월**

**읽을 점**
- 비용의 **75%가 입력 토큰**이다. 출력은 짧고 레포 자료(README·코드·커밋)가 비싸다. 비용을 줄이려면 출력이 아니라 **입력**을 줄여야 한다.
- 이전 추정(11.10)보다 1회 입력은 크고(약 8천~1.2만 토큰) 출력은 작다. 1인 최대치는 추정 120원보다 낮은 84원이다.

## 5. 수익 모델별 손익

### 5.1 학과 · 부트캠프 라이선스 (1순위)

| 가정 | 값 |
|---|---|
| 가격 | 학과 단위 연 200만 원 (월 약 16.7만 원) |
| 감당 가능 규모 | 사용자 1,000명 **최악(한도 꽉 채움)** 16.4만 원 < 16.7만 원 → 1건으로 손익분기 |
| 학생 1인당 환산 | 연 1만 원 라이선스 기준 원가는 연 약 1,000~2,000원 → 마진 80~90% |
| 비교 대상 | 유료 멘토링 시간당 약 5만 원 = 학생 1명 · 1회 비용으로 학생 25명을 1년 지원 |

### 5.2 개인 Pro (2순위)

| 항목 | 금액 |
|---|---|
| 가격 | 월 4,900원 |
| AI 원가 (한도 5배를 다 씀) | 약 420원 |
| 결제 수수료 (PG 약 3.5%) | 약 170원 |
| **1인 기여이익** | **약 4,300원** |
| 고정비 6만 원 충당 | **유료 사용자 14명** |
| 전환율 3% 가정 시 필요한 무료 사용자 | 약 470명 |

### 5.3 정리

| 단계 | 수익 | 월 비용 | 판정 |
|---|---|---|---|
| 지금 ~ 2027.2 (무료 + 파일럿) | 0 | 0원 (무료 플랜) ~ 6만 원 | 팀이 감당 가능한 수준. 무료 Postgres 만료만 주의 |
| 2027.3~ 학과 라이선스 1건 | 월 16.7만 원 | 1,000명 기준 7.7만 ~ 16.4만 원 | **흑자 또는 손익분기** |

## 6. 상용화 전에 할 일

| 순서 | 할 일 | 이유 | 크기 |
|---|---|---|---|
| 1 | **월 한도 되살리기** — `lib/aiCoachServer.ts`의 `consumeAiUsage`가 백엔드 `/api/ai/usage/consume`을 다시 부르게 | 지금은 한 사람이 비용을 무제한으로 쓸 수 있음. 위 표의 "최대" 숫자는 한도가 켜져 있을 때만 맞다 | 1시간 |
| 2 | 운영(Render) Redis의 `ai:tokens:*`로 같은 표를 다시 뽑기 | 지금 숫자는 로컬 21회, 개발자가 돌린 값 | 30분 |
| 3 | Vercel Pro 전환, Render Postgres 유료 전환 | 상업 이용 약관 · 30일 만료 | 결제만 |
| 4 | (선택) 입력 줄이기 — 레포 자료를 프롬프트 맨 뒤에 두고 지시문을 앞에 고정 → OpenAI 자동 프롬프트 캐시(같은 앞부분 1,024토큰 이상, 입력 50% 할인) | 비용의 75%가 입력 | 반나절 |
| 5 | 공식 가격 페이지에서 단가 재확인 | 아래 출처는 모두 제3자 집계 | 10분 |
