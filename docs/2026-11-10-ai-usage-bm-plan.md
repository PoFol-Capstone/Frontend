## 1. 지금 AI를 어디서 몇 번 부르나 (코드 기준)

| 기능 | 라우트 | 월 한도 (백엔드) | 분당 제한 (프론트) | 모델 | 비고 |
|---|---|---|---|---|---|
| 방향성 분석 | `ai/github-direction` | **5** | 3 | gpt-4o-mini | |
| 프로필 README 초안 | `ai/profile-readme` | **5** | 3 | gpt-4o-mini | |
| AI 이력서 | `ai/resume` | **3** | 3 | gpt-4o-mini | |
| 정리 카드 초안 | `ai/project-card` | **10** | 3 | gpt-4o-mini | |
| 게시글 README 요약 | `ai/summarize` | **없음** | 5 | gpt-4o-mini | 월 한도 밖 |
| 썸네일 | `ai/thumbnail` | **없음** | 10 | 기본값 `svg` → AI 호출 0 | `THUMBNAIL_PROVIDER=openai`일 때만 호출 |

**실제 사용량:** 운영 서버(Render) 데이터는 볼 수 없고, 로컬 Redis에는 11월 기준 2건(정리 카드 1, 방향성 1)뿐 → **실측 데이터는 아직 없다.** 아래 비용은 입력 크기 상한으로 계산한 추정이다.

### 코드에서 찾은 문제 3가지

| # | 문제 | 영향 | 해결 (작음) |
|---|---|---|---|
| 1 | **토큰 사용량을 기록하지 않는다** — OpenAI 응답의 `usage`를 버림 (`completeJson`) | 실제 비용을 모름. 발표에서 "비용이 얼마냐"에 추정으로만 답함 | `completeJson`이 `usage`를 기능 이름과 함께 기록 (Redis 월별 카운터 `ai:tokens:{feature}:{월}` 또는 로그 한 줄) |
| 2 | `summarize`는 **월 한도가 없다** | 분당 5회 × 계속 → 한 사람이 비용을 무제한으로 쓸 수 있음 | `consumeAiUsage("summarize")` 추가, 한도 20 |
| 3 | 분당 제한(`lib/rateLimit.ts`)이 **서버 메모리 Map** | Vercel 서버리스는 인스턴스마다 따로 → 사실상 약함 | 월 한도(백엔드 Redis)가 진짜 방어선. 분당 제한은 보조로 두고 문서에 명시 |

> 한도 차감은 OpenAI 호출 **전에** 한다 → AI가 실패해도 1회 차감. 비용 방어에는 안전하지만 사용자에겐 손해 — 실패 시 되돌리기는 2차.

## 2. 비용 추정

**가정:** gpt-4o-mini 입력 $0.15 · 출력 $0.60 / 100만 토큰 (제3자 가격표 기준, 발표 전 [공식 가격 페이지](https://developers.openai.com/api/docs/pricing) 확인), 1달러 = 1,400원, 한글 · 코드 섞인 입력 약 3자 = 1토큰.

### 2.1 호출 1회당

| 기능 | 입력 토큰 (상한 근거) | 출력 토큰 | 1회 비용 |
|---|---|---|---|
| 정리 카드 (지금) | ~5,000 (README 6천 자 + 설정 + 경로 400개 + 커밋) | ~1,200 | **약 2원** |
| 정리 카드 (P1 확장 후) | ~15,000 (코드 4만 자) | ~1,500 | **약 5원** |
| 방향성 분석 | ~3,000 | ~800 | 약 1.3원 |
| 프로필 README | ~2,500 | ~1,500 | 약 1.8원 |
| AI 이력서 | ~5,000 | ~2,000 | 약 2.8원 |
| README 요약 | ~2,000 | ~500 | 약 0.8원 |
| (계획) 구현 설명 | ~15,000 | ~1,500 | 약 5원 |
| (계획) 면접 질문 은행 | ~15,000 | ~3,000 | 약 6원 |
| (계획) 기술 추천 | ~5,000 | ~800 | 약 1.7원 |

### 2.2 사용자 1명 · 한 달

| 경우 | 계산 | 금액 |
|---|---|---|
| 지금 기능, **한도를 전부 씀** | 방향 5 + README 5 + 이력서 3 + 카드 10 | **약 45원** |
| 계획 기능까지, 한도 전부 (구현 5 · 면접 3 · 추천 5 추가, 카드 5원) | | **약 120원** |
| 보통 사용자 (한도의 25% 가정) | | **약 30원** |

### 2.3 서비스 전체 · 한 달 (계획 기능 기준)

| 월 활성 사용자 | AI 비용 (보통 · 최대) | 고정비 추정 (Vercel · Render · DB · Redis) |
|---|---|---|
| 100명 | 3천 원 · 1.2만 원 | 무료 플랜 ~ 5만 원 |
| 1,000명 | 3만 원 · 12만 원 | 약 7~10만 원 (유료 플랜 전환) |
| 1만 명 | 30만 원 · 120만 원 | 약 30만 원 |

**결론:** 월 한도가 있는 한 **AI 비용은 서버비와 비슷하거나 더 작다.** 사용자 1명이 최대로 써도 월 120원 수준이라 "학생 무료"가 비용 면에서 가능하다. 위험은 비용이 아니라 ① 측정이 안 되는 것(문제 1) ② 한도 밖 라우트(문제 2)다.

## 3. 비즈니스 모델

### 3.1 먼저 지킬 제약

| 제약 | 근거 | BM에 주는 영향 |
|---|---|---|
| 학생에게 돈을 받기 어렵다 | 타겟이 취준생 · 대학생, 대안이 ChatGPT(무료) · 블로그 | 개인 유료는 보조 수익으로만 |
| **사람인 API 데이터로 이용료를 받으면 안 된다** | 사람인 API 주의사항: 이용료 발생 · 이용 대가 수취 금지 | 사람인 데이터를 쓰는 화면(채용 트렌드)은 **항상 무료**. 유료 기능에 섞지 않음 |
| 신뢰가 핵심 가치 | 발표 Q&A — "평가가 아니라 스스로 점검" | 기업이 학생을 **점수로 거르는** 상품은 만들지 않음 (GitRoll식 피하기) |
| 사용자가 적다 (콜드 스타트) | 종합 문서 2장 | 사용자 수에 기대는 광고 · 매칭 수익은 3단계 이후 |

### 3.2 후보 비교

| 모델 | 누가 내나 | 가격 예시 | 장점 | 약점 | 판단 |
|---|---|---|---|---|---|
| **A. 학교 · 부트캠프 라이선스 (B2B2C)** | 학과 · 대학일자리센터 · 부트캠프 | 학과 단위 연 200~300만 원, 또는 학생 1인 연 1만 원 | 학생은 무료 유지. 기관은 "취업 준비 지원" 실적 · 수료생 포트폴리오 관리 필요. 점검 현황 집계 화면(학생 동의 기반) 하나만 추가하면 됨 | 영업 · 계약 주기가 김 (학기 단위) | **1순위** |
| B. 개인 Pro (프리미엄) | 학생 본인 | 월 4,900원 — 한도 5배, 공고 링크별 맞춤 점검 무제한, 면접 연습 무제한, PDF 내보내기 | 바로 만들 수 있음, 원가 낮음 (Pro 1명 최대 월 600원) | 전환율 낮음 (보통 2~5%), "무료 ChatGPT로 되는데?" | 2순위 — 1단계에선 결제 없이 **"Pro 체험"으로 수요만 측정** |
| C. 기업 채용 연계 | 기업 | 공개 포트폴리오 검색 · 스카우트 제안 건당 과금, 기업 챌린지 스폰서 | 단가 큼 | 학생 수가 쌓여야 함, "점수로 거르기"로 흐를 위험 → 본인이 공개 · 수락한 경우만 | 3단계 |
| D. 교육 과정 제휴 | 부트캠프 · 강의 플랫폼 | 기회 피드에서 연결된 수강 등록 수수료 | 기회 피드와 자연스럽게 맞음 | 추천이 광고로 보이면 신뢰 하락 → "제휴" 표시 필수 | 보조 |

### 3.3 추천 — 단계형

| 단계 | 시기 | 수익 | 할 일 | 성공 지표 |
|---|---|---|---|---|
| 1 | 지금 ~ 2027.2 | 없음 (전부 무료 + 월 한도) | 토큰 기록, 재점검 비율 측정, 교내 1개 학과 **무료 파일럿** | 재점검 비율 · 해결률 · 파일럿 학생 수 |
| 2 | 2027.3 ~ (새 학기) | **A. 학과 · 부트캠프 라이선스** | 기관용 집계 화면(학생 동의), 파일럿 결과 보고서로 영업 | 유료 기관 1곳 = 월 고정비 충당 |
| 3 | 사용자 1만 명 이상 | B 개인 Pro + C 채용 연계 | 결제, 기업용 화면 | Pro 전환율, 기업 계약 수 |

**손익분기 감:** 사용자 1,000명 기준 AI + 서버 월 약 15~20만 원 → 학과 라이선스 연 250만 원 1건(월 약 21만 원)이면 충당. "기관 하나면 학생 1,000명이 무료로 쓴다"가 발표 메시지.

## 4. 발표(PPT) 반영 계획

8장 구성은 유지하고 2곳만 바꾼다. 상세 숫자는 예비 슬라이드로.

| 슬라이드 | 바꾸는 것 |
|---|---|
| 6 기술 & 설계 | 오른쪽 "핵심 설계"에 4번째 줄 추가: **AI 비용 통제** — 기능별 월 한도(백엔드 Redis) · 호출 전 차감 · 분당 제한, "사용자 1명 최대 월 약 45원" |
| 8 다음 단계 & 마무리 | 왼쪽 아래에 **BM 3단계 띠**: 무료 + 파일럿 → 학과 · 부트캠프 라이선스 → 개인 Pro · 채용 연계. 한 줄: "기관 하나면 학생 1,000명이 무료로" |
| 예비 슬라이드 (Q&A용) | 2.1 · 2.2 표 + 3.2 비교표 + 사람인 약관 제약 — "수익 모델은?", "운영비는?" 질문이 나오면 꺼냄 |

**발표 전에 할 일 (숫자를 추정에서 실측으로):**
1. 토큰 기록 추가 (문제 1) — 반나절
2. 골든셋 레포 5개로 각 AI 기능을 한 번씩 실행 → 실제 토큰 · 원 단위 비용으로 2.1 표 교체
3. 공식 가격 페이지에서 단가 재확인

## 6. 확인이 필요한 것

- gpt-4o-mini 단가 — 제3자 가격표 기준, 공식 페이지 미확인
